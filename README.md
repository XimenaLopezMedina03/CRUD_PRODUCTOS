# 🛒 Sistema de Gestión de Productos

**Descripción:** Sistema CRUD desarrollado con PHP, PDO, MySQL, HTML y CSS para la gestión de productos.

**Tecnologías:** 
- PHP
- PDO
- MySQL
- HTML5
- CSS3

**Funcionalidades:**

- Registrar productos
- Buscar productos
- Editar productos
- Eliminar productos
- Conexión a MySQL mediante PDO
- Programación Orientada a Objetos
